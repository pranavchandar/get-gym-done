A complete, self-contained spec for the Routine page of Get Gym Done — the landing screen of the Workouts tab, headed "Routine / 5 Day Illustrated". It is a browser of all five training days, each card showing how the day is built and how many times it has been logged. Purpose

The Routine page answers one question: "What does my whole program look like, and how consistent have I been on each day?" Where the Today tab is forward-looking (one "up next" card), the Routine page is the at-a-glance index of the entire split — all five days in one scroll, each summarising its exercises, set volume, and lifetime completion count. Tapping any day drills into its Day Overview.

It is reached by selecting the Workouts item (dumbbell icon) in the bottom tab bar. It is a pure read/browse surface — nothing here mutates data; it only navigates.

Read-only index

Five days.
One scroll.

Every training day in the active split renders as a tappable card with a big lime index numeral, a name, an "N exercises · M sets" line, a lifetime completion counter, and a horizontally-scrolling strip of exercise chips.

The header is fixed copy — eyebrow "Routine" over the split name "5 Day Illustrated" set in Anton 36px. No filters, no search, no FAB. Tap a card → Day Overview.

Anatomy

The screen is a vertical flex column: a fixed device status bar, a scrollable body, a fixed bottom tab bar, and the device gesture nav. The body holds a two-line header and a list of five identical day cards. Each card has the same internal sub-structure.
