01

Product overview

Get Gym Done is a workout-tracking app built around a recurring multi-day split. The reference program is a 5-day split (Upper / Lower / Shoulders & Arms / Legs (Quad) / Back & Chest) with 26 exercises, each carrying form cues and prescribed sets × reps. The app auto-detects which day is next from the user's log, opens straight into it, and lets the user log sets with a single big CTA. Progress is reviewed via charts in the Profile tab.

Design principles

  • One screen, one job. Each surface does exactly one thing — pick, log, or review.
  • Fast logging beats rich logging. Pre-fill from last session, big tap targets, single-tap commit.
  • Calendar-first home. The home screen surfaces the next workout automatically; override is always one tap away.
  • Honest placeholders. Exercise demos and anatomy use labeled striped placeholders, never fake art.
  • Bold sport aesthetic. Warm near-black ground, a single electric-lime accent, condensed display type, oversized numerals.
North star

"Open app → know what to lift → log it → leave." The big "Complete Set" CTA is the most-tapped pixel in the product. Anything that slows that loop is wrong.

Shared components

Every screen is assembled from this kit. Specs here are the source of truth; screen sections reference them by name.

Phone frame & chrome

  • Frame: 412 × 892px, border-radius:44px, 8px solid #1a1813 border, large soft drop shadow. Inner content clipped to the radius.

The honest stand-in for exercise GIFs and any missing imagery. A repeating-linear-gradient(-45deg, …) of two white-alpha stripes (0.04 / 0.08) over --surface-2, with a centered lowercase mono label (11px, --fg-3, .08em). MuscleMap

A stylized front/back body silhouette in a 100×200 viewBox, rendered as flat blob <path>s. Muscle groups light up: active = --accent fill, inactive = --surface-3 fill, --line stroke. Accepts active (array of muscle names, case-insensitive) and side ('front' default | 'back'). Recognized names: Upper Chest, Chest, Shoulders, Front/Side/Rear Delts, Biceps, Triceps, Forearms, Abs/Core, Quads, Hamstrings, Glutes, Adductors, Calves, Lats, Mid Back, Posterior Chain. Not anatomical art — intentionally abstract; replace with a real anatomy system in production.

LineChart & Sparkline

  • LineChart — SVG, 320×height viewBox, preserveAspectRatio:none. Draws a filled area (accent at 0.14 opacity) under a 2.4px accent stroke line, a dot at every point (last point larger, 4px, with a --bg ring). Optional min/max axis labels in mono. Accepts data: [{x, y}], height, color.
  • Sparkline — tiny inline line, no fill, for card corners.

05

Navigation & app state

Top-level state is a single state machine in the root App component. Onboarding is linear; the main app is a tab shell with modal takeovers.

// Top-level screen machine
screen: 'splash' | 'split' | 'method' | 'customize' | 'app'

// When screen === 'app', a tab + view drive what renders:
tab:     'home' | 'workouts' | 'profile' | 'settings'
appView: 'home' | 'day-overview' | 'workout' | 'complete'
openDayIdx: 0–4            // which day is being viewed/worked
workoutLog: [{date, day}]   // grows when a session completes
tweaks: { palette, theme, layout, unit, … }

Flows

  • Onboarding: splash → split → method → (custom only) customize → app. "Curate for me" skips customize.
  • Workout: home → [day-overview] → workout (per-exercise loop) → complete → home. The home CTA can skip straight to workout.
  • Next-day logic: nextDayIndex = lastLog ? (lastLog.day % 5) : 0. After day 5 wraps to day 1. User can override on any tap; the override is what gets logged.
  • Modals (override sheet, keypad, exercise picker) overlay the current screen without changing screen/appView.

Per-screen specifications follow. Each cites tokens and components from §02–04.

Active workout — 4 variants

Core loop

The highest-traffic surface. The same session data renders in one of four user-selectable layouts (Tweaks → Layout variant). All four share: a top bar, exercise progress dots, a rest-timer bar, and the bottom Complete-Set CTA. The variant is a global preference applied to every exercise.

Shared chrome

  • WorkoutTopBar — close IconBtn (exit) · centered {day name eyebrow + "{exIdx+1} / {total}" Anton 18px} · more IconBtn. Below it a full-width .progress bar tracking total sets completed across the whole session.
  • ExerciseDots — one thin bar per exercise; done = accent, active = --fg, upcoming = --surface-3. Tappable to jump.
  • RestBar — appears after a completed set: 22% accent-tint bg, accent top/bottom border, timer icon + "RESTING · {s}s" (Anton 18px) + outlined "Skip" button. Counts down from 90s.
  • CompleteSetCTA — pinned bottom. While sets remain: "Complete Set {n}" with inline "{weight}{unit} × {reps}" preview. When the exercise is done: turns into "Next exercise →" (or finishes the session on the last exercise). An "Undo last set" ghost button appears above once any set is logged.

Set row

The atomic logging unit. Three states: active (accent border + 8% tint), done (14% accent tint, accent set-number + check), idle.

  • Layout: set number (Anton, zero-padded "01") · weight cell · "×" · reps cell · 18px done-check slot.

  • Tap the number (not the steppers) opens the keypad sheet for big edits.
  • Add set — dashed button below the list; new set inherits the previous set's weight + reps.

Complete-Set CTA

Bottom .btn-cta-huge variant showing "Complete Set {n}" + inline "{weight}{unit} × {reps}". On tap: marks the current set done, starts the 90s rest timer, toasts "Set {n} logged · 90s rest". After the last set: becomes "Next exercise →".

Keypad sheet

Opened by tapping a weight/reps number. Big accent value display (Anton 80px) + quick-adjust chips (weight: ±1.25/±2.5/±5; reps: ±1/±2/±5), a 3-col numeric keypad (7-8-9 / 4-5-6 / 1-2-3 / . 0 ⌫), and a "Save" CTA.

Data model

All reference data lives in one module. Shapes:

The reference program is the 5-day split: Day 1 Upper (Pulldown, Incline Smith, T-Bar Row, Lateral Raise, Close-Grip Bench, Barbell Curl), Day 2 Lower (Deadlift, Leg Ext, Seated Ham Curl, Seated Calf, Decline Crunch), Day 3 Shoulders & Arms (7 lifts), Day 4 Legs Quad (6 lifts), Day 5 Back & Chest (5 lifts). Day 1/2 use 6–8 reps, Day 3+ use 8–12; each exercise carries 3–4 form cues lifted from the source PDF. Units: all weights stored in kg; convert to lbs at display only (kg × 2.20462, rounded to nearest 0.5).
